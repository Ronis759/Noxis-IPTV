# Noxis IPTV (Android TV / ТВ-бокс)

Нативное приложение: Kotlin + Media3 ExoPlayer. Играет http/https, HLS и MPEG-TS без ограничений CORS, а также udp:// (multicast) и rtsp://.

Это только плеер: ни каналов, ни плейлистов в нём нет. Откуда брать плейлист и есть ли у вас право на его контент — ваша ответственность.

## Быстрый старт
1. Скачайте APK из раздела **Releases** (или соберите сами, см. ниже) и установите на бокс. Разрешите установку из неизвестных источников.
2. Скопируйте `servers.example.txt` в `servers.txt`, впишите свои адреса и перенесите файл на бокс (флешка, Downloader, ADB).
3. В приложении: **Настройки → Загрузить файл…**, выберите `servers.txt`, затем нужный сервер. Дальше он запоминается.

## Серверы
Список хранится в приложении, а не в APK. Формат файла — по строке на сервер:

```
Название | ссылка на плейлист M3U | ссылка на программу передач (необязательно)
```

- Выбрать другой сервер: пункт **⇄ Сервер** в списке каналов или **Настройки → Выбрать сервер**.
- Можно загрузить и готовый `.m3u` — он станет локальным плейлистом (сам не обновляется).
- Без файла: **Настройки → Дополнительно** — вписать ссылку на плейлист вручную.
- Если у бокса нет окна выбора файлов: `adb push servers.txt /sdcard/Android/data/app.iptv.tv/files/`.
- Файл `servers.txt` внесён в `.gitignore`. Не публикуйте его: в ссылках бывают логины и ключи.

## Управление
- **OK** — список каналов (слева — группы, первые пункты: «Настройки», «Архив», «Сервер», «Группы…»)
- **←** — архив (слева — дни, справа — передачи). Также: **OK** → колонка значков слева → **↺ Архив**, или удержание OK на канале → **↺ Архив канала**
- Во время архива **←/→** — перемотка на 30 с (удержание — непрерывная, с ускорением), **Назад** — вернуться в прямой эфир
- Если архив не открылся, приложение само пробует другие форматы ссылки (в т. ч. Flussonic) и запоминает рабочий для сервера
- **↑/↓**, CH+/CH− — переключение каналов, **Назад** — закрыть панель
- **Меню / Info** — настройки / информация о канале

## Избранное и группы
- **Удерживайте OK на канале** — добавить в избранное / убрать (запасные клавиши: Меню, «*», жёлтая). Избранные отмечены ★, список — группа **★ Избранное**.
- **Красная кнопка или «*»** при просмотре — добавить / убрать текущий канал из избранного.
- **Удерживайте OK на группе** — скрыть её. Вернуть или скрыть несколько групп: пункт **☰ Группы…**
- Скрытые группы не показываются в списке и в «Все», а ↑/↓ их пропускают. Избранное и скрытые группы общие для всех плейлистов.

## Внешний вид
- **Настройки → «Затемнение подложки списков»**: насколько непрозрачна подложка за списком каналов, телепрограммой, окнами групп и серверов (30–100 %, по умолчанию 95 %). **OK** — следующее значение (шаг 10 %), **◄ / ►** — точная подстройка на 5 %. Под кнопкой — пример на ярком фоне; значение применяется сразу и запоминается.

Адрес программы передач по умолчанию не задан: приложение берёт его из заголовка плейлиста (`url-tvg` / `x-tvg-url`). Своё значение можно указать в **Настройки → Дополнительно**.

## Устойчивость воспроизведения
- Обрыв связи, закрытие потока сервером или «зависание» буферизации дольше 20 с — автоматическое переподключение (до 5 попыток).
- User-Agent, с которым сервер ответил на запрос плейлиста, запоминается и используется плеером (если не задан вручную).
- Кодировка плейлиста определяется автоматически: сначала строгий UTF-8, при ошибке — windows-1251.
- Размер ответа ограничен: плейлист — 64 МБ (после распаковки gzip), логотип — 4 МБ, ответ GitHub — 2 МБ. Слишком большой ответ отбрасывается.
- В сообщениях об ошибках ссылки сокращаются до «схема://хост»: логины и ключи на экран не попадают.
- Сырой MPEG-TS (не HLS) разбирается с флагами `ALLOW_NON_IDR_KEYFRAMES` и `DETECT_ACCESS_UNITS` — быстрее старт и меньше артефактов на «грязных» потоках.
- Кэш плейлиста хранится отдельно для каждой ссылки; если сервер недоступен, показывается сохранённый список.
- Программа передач разбирается потоково: в памяти остаются только передачи каналов из плейлиста за нужное число дней.

## Сборка и подпись (GitHub Actions)
APK подписывается вашим личным ключом, он хранится в GitHub Secrets и в репозиторий не попадает. Ключ нужен, чтобы новые версии ставились поверх старых и чтобы никто чужой не смог выпустить «обновление».

**Один раз создайте ключ** (нужен JDK 17+; на Windows в PowerShell):

```powershell
keytool -genkeypair -keystore release.keystore -alias noxis -keyalg RSA -keysize 2048 -validity 10000
[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.keystore")) | Set-Clipboard
```

Второй командой содержимое ключа в формате base64 копируется в буфер обмена. Файл `release.keystore` сохраните в надёжном месте: потеряете его — обновить уже установленные копии будет нельзя.

**Добавьте Secrets** в репозитории: *Settings → Secrets and variables → Actions → New repository secret*:

| Secret | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое буфера обмена (base64 ключа) |
| `KEYSTORE_PASSWORD` | пароль хранилища, введённый в keytool |
| `KEY_ALIAS` | `noxis` |
| `KEY_PASSWORD` | пароль ключа (в keytool по умолчанию совпадает с паролем хранилища) |

**Сборка:** любой push в `main` собирает APK (вкладка **Actions → Build APK → Artifacts → iptv-tv-apk**). Если Secrets не заданы, APK подписывается временным ключом: поставить его можно, но обновить поверх нельзя.

**Релиз:** *Actions → Build APK → Run workflow*, галочка **Опубликовать релиз**. Создаётся Release `v<номер запуска>` с `app-release.apk`; номер совпадает с `versionCode`.

Локальная сборка: `./gradlew assembleRelease` (Windows: `gradlew.bat assembleRelease`) — без переменных окружения подпись отладочная.

## Тесты
`./gradlew testDebugUnitTest` — юнит-тесты разбора M3U, servers.txt, ссылок архива, кодировки, лимитов, часового пояса и кэша программы. В GitHub Actions они запускаются перед каждой сборкой.

## Автообновление из GitHub
1. Впишите репозиторий в `app/src/main/res/values/strings.xml` → `github_repo` (формат `владелец/имя`, репозиторий должен быть публичным). Пусто — обновления отключены.
2. После публикации релиза приложение при запуске (не чаще раза в 6 часов) или по кнопке **Проверить обновления** сравнивает свой `versionCode` с номером последнего релиза и предлагает установить новую версию.
3. Автообновление включено только в сборках, подписанных вашим постоянным ключом (Secrets заданы). В локальных сборках и в CI без Secrets APK подписан временным ключом, и Android не установил бы новую версию поверх: такая сборка обновления не предлагает.
4. При первой установке Android попросит разрешить «установку из неизвестных источников» для приложения.
